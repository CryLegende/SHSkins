## Présentation

Applique les skins SkyHand a la connexion

Utilisé sur : **Proxy**.

## Configuration

Fichiers par défaut repris du serveur (secrets remplacés par `CHANGE_ME`) :

- `config.yml`

## Compilation

Java 21 et Maven :

```bash
mvn clean package
```

Le jar est généré dans `target/`.
